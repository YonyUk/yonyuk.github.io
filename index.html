01 — About

What I do

I focus on building software with clean architecture and well-justified technical decisions. My main project is PyLGEN, a Python framework for building compilers and interpreters, published on PyPI with documentation on ReadTheDocs.

On the backend I've built production-style services with FastAPI + SQLAlchemy and with .NET (C#) + Entity Framework Core, applying patterns like Circuit Breaker, Repository and JWT authentication in microservices deployments orchestrated with Docker. On the frontend I work with React 18 + TypeScript.

Right now I'm expanding into AI engineering, specializing in multi-agent systems with LangGraph. I'm looking for a team where I can contribute full-stack expertise and grow as an engineer building intelligent applications.
